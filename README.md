# Module 6 · Maps: інструкція

## Що в архіві
```
index.html            службова сторінка: готові iframe-коди для Kwiga (відкрий її на Vercel)
lessons/              один файл = один урок Kwiga (03–08) + vocabulary.html
assets/               карти: meadow.jpg, porteliz.jpg, elmsworth.jpg, seaborne.jpg (карти «було / стало» в одному зображенні)
shared/core.css       єдиний вигляд усіх уроків
shared/core.js        спільна логіка: карти, вправи, прогрес, збереження відповідей, авто-висота
data/graphs.js        усі карти (шлях до картинки + опис) в одному місці
data/lesson-XX.js     зміст уроків (вправи, пояснення, моделі)
data/vocab.js         словник (Основа / Додатково), один на весь модуль
shared/vocab.js       панель словника в кожному уроці
```

## Уроки
03 Introduction · 04 Overview · 05 Як читати карти й групувати зміни · 06 Main Body 1 · 07 Main Body 2 · 08 Final Task (три повні відповіді: Seaborne, Port Elizabeth, Elmsworth) · vocabulary.

Нумерація 03–08 збігається з Module 1, 4 і 5. Перші три уроки модуля (старі тренажери 1–2) лишаються як є й будуть перебудовані пізніше.

## Як розмістити
1. GitHub → новий репозиторій `ielts-maps` → Add file → Upload files → перетягни **вміст** папки (index.html, lessons, shared, data, **assets**). Папка assets обов’язкова: без неї карти не відображаються.
2. Commit changes. Vercel (Add New → Project → цей репозиторій → Deploy) оновить сайт сам за ~1 хвилину.
3. Відкрий `https://ТВІЙ-САЙТ.vercel.app/` (адреса саме з Vercel, не домен Kwiga), впиши її в поле й скопіюй код iframe для кожного уроку.
4. У Kwiga в кожному уроці: блок «HTML-код» → встав код.

## Як замінити діаграму
Поклади новий файл у `assets/` (jpg, png або svg) і в `data/graphs.js` зміни поле `img` (наприклад `'../assets/meadow.jpg'`). Поле `alt` — короткий опис для скрінрідерів. Код не чіпай. Учень може клікнути на діаграму, щоб збільшити її.

## Як змінити вправу
Відкрий `data/lesson-03-introduction.js` (або інший) і правь текст. Типи блоків: example, gap, choose, pick, cells (тільки для таблиць), **sort** (розподіли зміни / частини тексту по колонках), rewrite, write, build, logic, fullwrite.

## Вправа «розподіли» (sort)
Учень клікає на пункт, потім на колонку-фазу. Поля: `cols` (назви колонок), `items` (`[текст, номер правильної колонки]`, нумерація з 0), `prompt`, `why` (пояснення після успіху), `hintWrong` (підказка при помилці).

## Збереження відповідей
- Автоматично в браузері учня (localStorage). Кнопка «📝 Мої відповіді»: скачати .txt, скопіювати, зберегти як PDF.
- Якщо браузер блокує сховище в iframe (private mode, деякі налаштування Safari), вправи працюють, але відповіді не переживуть перезавантаження. Тому в підказці учням радимо скачати файл.
